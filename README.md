# StyleAI
Vibe Coded website using base44.

## AI Fashion Style Assistant

StyleAI is an AI-powered personal fashion assistant that helps users
discover suitable outfits based on their uploaded photo and selected occasion.

## Features

- User Registration and Login
- Upload Fashion Photo
- Select Occasion
- AI-Powered Style Recommendations
- Apparel Recommendations
- Jewelry Recommendations
- Footwear Recommendations
- Complete Look Suggestions
- Save Favorite Looks
- Style History
- Product Recommendations

## Supported Occasions

- Formal
- Casual
- Festive
- Party
- Wedding
- College
- Office
- Traditional
- Date
- Travel

## Technology

- Base44
- AI-powered recommendation system
- Responsive Web UI
- Database
- Authentication
